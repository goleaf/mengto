## Rules

- A default factory creates a valid, constraint-compliant record.
- Helpers create only intentional graph relationships; large graphs are opt-in.
- Fixed reference seeders are idempotent and use stable natural keys.
- Demo seeding is environment-gated and never truncates existing data.
- Internet access is prohibited during factory and seeder execution.
