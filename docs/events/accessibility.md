# Event Accessibility

`ForumEventAccessibilityStatus` distinguishes confirmed, partial,
venue-supplied, on-request, not assessed, and inaccessible states. Cards and
workspace panels present text labels rather than a color-only badge.

Current forms use semantic labels, fieldsets, error summaries, keyboard
controls, responsive lists, loading targets, and offline notices. Browser
viewport, forced-colors, and long-translation evidence is recorded only after
the final verification run.
