# Competitions

Competition is a controlled event type with a durable implementation subset.
There is no betting or gambling model and no float-based money or scoring
field.

The current tree contains relational categories, rules, criteria, entries,
entry pets, judge assignments/conflicts, precise scores and revisions,
result versions, history, appeals, and Actions for creation, submission,
assignment, scoring, correction, finalization, and appeal. This is
**implementation present; verification pending**, not a production-complete
feature: the representative manifest and factory gate are incomplete, no full
reachable workflow and release matrix has passed, and prizes/certificates and
provider-backed financial behavior remain absent.
