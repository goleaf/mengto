# Event Media And Privacy

Registration stores explicit photo-consent state. Exact locations, online
links, emergency plans, attendee notes, invitations, and private review safety
feedback are encrypted or hidden from normal serialization. Attendee lists are
not public by default.

Private and organization event locations reuse the canonical `Place` access
boundary. Exact facts are revealed only to a current manager or an account-
bound, purpose-bound, unexpired grant and every successful reveal is audited.
An `event_attendance` grant also requires the matching event and a registration
whose current state permits access details; form submission or payment alone is
not sufficient.
Location changes preserve encrypted history and revoke stale grants. Event
cards, public metadata, Livewire state, and occurrence snapshots retain only
the public region and canonical IDs.

Versioned recording consent, guardian workflow, restricted media indicators,
event gallery moderation, expiring exports, and per-record retention schedules
remain open scope.
