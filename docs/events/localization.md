# Event Localization

Platform-controlled event types, statuses, registration states, pet modes,
accessibility, verification, recurrence, team roles, actions, validation, and
history labels exist in EN, LT, and RU. Session types, status, reservation
policies, team roles, field labels, validation, feedback, and empty states use
the same catalogue. Recursive key parity is tested.

Dates use event timezone-aware Carbon values and prices use integer minor
units. The repository does not advertise RTL support because none of the three
supported locales is RTL.
