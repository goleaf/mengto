# Event Registration

Registration is occurrence-aware and supports several managed pets. The
service locks capacity, rejects duplicates, preserves the accepted event
version, selected participant/pets, consent, locale, timezone, answers, price,
and submission timestamps in a snapshot.

Organizer approval updates participant and pet status independently. Unknown,
expired, disputed, or manual-review pet eligibility blocks check-in. Check-out
records an attended state and per-pet departure without penalizing an early
welfare departure.
