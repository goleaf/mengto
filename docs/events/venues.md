# Event Venues

The current aggregate stores a public location scope separately from encrypted
exact location and online access. Only owner, administrator, eligible attendee,
or active team roles may view access details. Directory cards and metadata use
the public scope only.

A reusable venue/area/room model, route geometry, expiring location grants,
and offline venue packages are not yet implemented. Existing place records are
not duplicated or silently reclassified as venues.
