## Report Contract

Each specialist report must include:

1. exact files and symbols inspected;
2. observed commands and outputs or counts;
3. factual findings separated from recommendations;
4. preservation, privacy, query, localization, and accessibility risks that
   apply to the assigned scope;
5. proposed tests and acceptance criteria;
6. a clear `DONE`, `DONE_WITH_CONCERNS`, `NEEDS_CONTEXT`, or `BLOCKED` status.

Reviewers remain independent from implementation. The final reviewer receives
a frozen attributable diff and does not rely on implementer summaries as
evidence.
