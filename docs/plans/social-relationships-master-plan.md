# Social Relationships Master Plan

Date: 2026-07-31

Status: source preserved and atomized; first foundation package implemented

## Contract

The social revision contributes 3,210 stable `social.*` atomic requirements to
the indivisible forum master without renumbering the previous 11,419 IDs. The
generated phase index is authoritative for assignment. A requirement becomes
verified only after its own acceptance behavior has file and test evidence.

## Phase 26: Preservation, Audit, And Decisions

Preserve the raw revision and checksum, regenerate the catalogue, inspect the
live schema and prototype state, record gaps/assumptions/conflicts, and select
exact work-package IDs before production changes.

## Phase 27: Relationship And Follow Foundation

Create canonical actor adapters, typed directed/symmetric relationships,
follows, owner friendship, close circle, family/professional separation,
actor settings, viewer-aware lists/counts, and compatibility reporting.

## Phase 28: Requests, Safety, And Moderation

Implement the full request lifecycle, idempotency/races, rate and repeat
limits, blocks/restrictions/mute, account-wide scope, reports, anti-fraud,
minor protections, appeal integration, and high-priority invalidation.

## Phase 29: Pet Friendship And Safe Meetings

Add two-sided pet-manager consent, contextual friendship types, neutral
compatibility cards, first-meeting plans, temporary contact/location,
check-in, incidents, pauses, and safe termination.

## Phase 30: Recommendation And Search

Build permissioned, explainable and diverse recommendations; opt-out/hide
controls; location minimization; profile search and filters; transliteration;
saved searches; anti-enumeration; and block/decline exclusions.

## Phase 31: Messaging, Groups, Events, Privacy, Notifications

Add message requests, actor attribution, link/media protections, call/read
controls, group/event invitations, walks, temporary chats, social-graph
visibility, quiet hours, and lifecycle-aware notification delivery.

## Phase 32: Interface, Accessibility, Localization

Deliver class-based Livewire mobile/desktop surfaces, complete keyboard and
screen-reader operation, 320px/200% reflow, stable textual statuses, offline
and weak-network states, and EN/LT/RU parity with source-preserving translation.

## Phase 33: Release And Quality

Complete the minimum release contract, abuse and value metrics, privacy-safe
analytics, query budgets, migration/backfill/rollback, full quality gates,
browser verification, operations, and documentation.

## Phase 34: Scenario Verification

Execute all ideal scenarios end to end, including follows, owner/pet
friendship, first meetings, spam, blocks, minors, shelters, transfer,
incidents, and memorial behavior. Link every result to atomic evidence.

## Cross-Phase Invariants

- No social edge grants ownership, management, medical, device, or location
  authority.
- Real user attribution and server-side authorization are mandatory.
- Existing profile IDs, prototype state, groups, events, reports, posts, and
  pet lifecycle history are preserved.
- No raw SQL, Blade query, unbounded query, or aggregate inside a loop.
- Additive migrations have reversible schema changes and non-destructive
  bounded backfills.
- Security-sensitive cache and index updates have priority over feed freshness.
