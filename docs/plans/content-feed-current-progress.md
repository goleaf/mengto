## Open Boundaries

- encrypted prototype feed state is compatibility data, not shared content;
- persistent photo rows need an additive canonical relation without data loss;
- specialized domains remain authoritative and are linked, not copied;
- queue-backed video/live processing and external AI are not configured;
- native mobile background features are outside the current web runtime;
- phases 36-44 remain open until independently implemented and evidenced.
