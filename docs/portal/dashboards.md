# Portal Dashboards

The portal currently uses module-specific dashboards and shared panel/stat
components rather than a configurable widget registry. `ForumEventWorkspace`
is the organizer/participant event dashboard and conditionally exposes
occurrences, capacity, registration queue, communications, access, and
attendance actions.

Role-specific customizable home dashboards, widget persistence, priority
aggregation, organization workspace switching, and measured payload budgets
remain open Point 12 scope. Point 13 did not create an isolated dashboard
theme.
